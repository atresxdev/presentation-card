# TARJETA DE PRESENTACION (ART)
Tarjeta de presentación para la cuenta ATRESxART

## VERSION 1

**REQUISITOS:**
- Foto de perfil.
- Un poco de información sobre mi.
- Enlace a redes sociales.
- **Debe** ser responsive.

**STACK:**
Las tecnologías que se usarán para desarrollar este proyecto son
- **HTML y CSS:** Al ser una web sencilla no es necesario usar frameworks.
- **JavaScript (tal vez):** Dependiendo de que ideas plantee durante el desarrollo podría agregar algo de lógica de JavaScript.
